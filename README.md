# Rock, Paper, Scissors

This Python program simulates a game of Rock, Paper, Scissors between the user and the computer.

The program:

-Allows the user to choose rock, paper, or scissors
-Generates a random choice for the computer
-Compares both choices
-Displays whether the user wins, loses, or draws

## How to Run

Make sure Python is installed, then run:

```bash
python flexisaf_deliverable.py
```

## Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Matching choices result in a tie
